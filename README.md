# 💎 Advanced Pricing Cards Widget

A sleek, responsive, and production-ready pricing component designed for SaaS products, web services, and startups. Built with modern semantic HTML5, custom CSS3 properties, and interactive JavaScript features.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

---

## ✨ Features & Upgrades

- **Interactive Billing Toggle:** Switch seamlessly between **Monthly** and **Yearly** billing options with auto-calculated 20% discounts.
- **Dynamic Price Updates:** JavaScript listener updates pricing amounts smoothly without page reloads.
- **Modern Dark UI Aesthetic:** Features clean contrast, glowing badges, subtle scaling effects on hover, and an enhanced "Most Popular" highlighted plan.
- **Refreshed Testimonial Section:** Integrated a high-resolution, professional profile portrait using Unsplash.
- **Fully Responsive Grid:** Automatically adapts from multi-column desktop layouts to single-column mobile arrangements.
- **Smooth Action Handlers:** Buttons include built-in interactive feedback states (`Redirecting...`).
